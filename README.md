# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入自己的 WAV，在谱图拖选或用表单输入数值。添加选区后生成修复，切换原声与修复试听，再下载 PCM WAV。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 录音识别。保留声道数、采样率和帧数。
- 谱图计算。窗长变化使真实频格宽度变化。
- 频带衰减。污染选区附近频带能量下降。
- 旁路重建。无选区的输出逐帧等价。
- 量测和 PCM 输出。保持源帧数并给出逐声道差值。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。

## 逐项核听交接

页面下方的「逐项核听交接」面板支持两位剪辑师在同一份 WAV 上协作：

1. 发送方在频谱上添加选区，填写核听段帧范围、带内量测频点与可选的保留带外频点，打包交接记录。可能改到同样点（含间接相连）的选区自动合并为一个核听项。
2. 接收方载入交接记录（可另选接收稿 WAV），查看逐声道修后读数；普通合入或按项授权重做并指定保留的带外频点。
3. 合入逐项判定：读数容差 2 码、写位冲突、削波、未授权改动或声线无法分辨时该项保留接收稿，其余照常合入。
4. 重开时凭合入记录与吻合的修后读数确认已合入；同一 PCM 另存为无记录 WAV 仍按本地副本判冲突。
