# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入自己的 WAV，在谱图拖选或用表单输入数值。添加选区后生成修复，切换原声与修复试听，再下载 PCM WAV。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 单喇叭交付

访问 `http://127.0.0.1:4813/fold.html`（或首页"单喇叭交付"链接）打开单喇叭交付工作台。打开双声道录音后在波形上拖动圈时间，同一频率刻度比较各频带合计有效电平与等权折叠（单位码，合计低于 8 码无有效内容）。原来有声、双侧均有声且折叠后低至少 9 dB 的频带可勾选挽回，单侧有声不标相消。生成成品后对听普通折叠与成品，下载原采样率等长单声道 PCM16。单声道原件不可启用。

## 工作流

- 录音识别。保留声道数、采样率和帧数。
- 谱图计算。窗长变化使真实频格宽度变化。
- 频带衰减。污染选区附近频带能量下降。
- 旁路重建。无选区的输出逐帧等价。
- 量测和 PCM 输出。保持源帧数并给出逐声道差值。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。
