# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入自己的 WAV，在谱图拖选或用表单输入数值。添加选区后生成修复，切换原声与修复试听，再下载 PCM WAV。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 录音识别。保留声道数、采样率和帧数。
- 谱图计算。窗长变化使真实频格宽度变化。
- 频带衰减。污染选区附近频带能量下降。
- 旁路重建。无选区的输出逐帧等价。
- 量测和 PCM 输出。保持源帧数并给出逐声道差值。
- 串漏校准与还原。见下节与 `BLEED.md`。

## 串漏修复

双声道节目有串漏、接头变动使个别独奏失准时，打开 `/bleed.html`（首页右上角
「串漏修复」）。每路圈三段互不重叠的独奏作校准，另圈一段与校准分开的待修
节目；工具只凭独奏拟合每方向固定、延迟 1 至 8 帧的串漏关系，再还原节目中
两路直达声。缺证、校准不一致或歧义时会指出方向、保留原声且不出成品。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口，`BLEED.md` 了解串漏细则。
构建命令检查语法、服务装载与串漏自检。
