# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入自己的 WAV，在谱图拖选或用表单输入数值。添加选区后生成修复，切换原声与修复试听，再下载 PCM WAV。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 录音识别。保留声道数、采样率和帧数。
- 谱图计算。窗长变化使真实频格宽度变化。
- 频带衰减。污染选区附近频带能量下降。
- 旁路重建。无选区的输出逐帧等价。
- 量测和 PCM 输出。保持源帧数并给出逐声道差值。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。

## 落锁对轨

页面下方「落锁对轨 · 两次落锁时刻搬迁」工作台：

1. 点「打开落锁样本」（或导入自己的双声道 PCM WAV）。
2. 在波形上横向拖动，圈出零起算的**改动段**（也可精确填首尾帧）。
3. 为两次落锁分别填写**原声搜索范围**与**目标帧**。
4. 点「① 辨认撞击 · 显示零起算源帧」：左右两路同时确认且范围中唯一时，卡片显示零起算源帧与左右强弱；不唯一会提示重新圈选。
5. 点「② 生成落锁搬迁」：按原顺序把各源帧起的 **32 帧双路原码**搬到目标。段首尾各 16 帧与圈外原样；目标片之间及与保留区至少留 2 帧接声。
6. 可「听原声 / 听搬迁结果」，并下载与试听同一份**原采样率、等长、双声道 PCM16 WAV**。接声不满足 5% 包络规则时保留原声并提示调整目标帧。

面板还提供两个示例预设：把第 1 路搜索范围扩大到含入两次撞击（演示“重圈”），以及把第 1 目标移到段尾渐弱处（演示“接声无解、调整目标”）。

HTTP 入口：`GET /api/spectral-mend/lock-demo`、`POST /api/spectral-mend/lock-inspect`、`POST /api/spectral-mend/lock-move`（另挂 `/api/lock/demo|inspect|move`）。全部帧为零起算半开区间。

```bash
node scripts/lock-checks.mjs   # 落锁规则的 23 组有界断言
npm test                       # node --test test/
```
