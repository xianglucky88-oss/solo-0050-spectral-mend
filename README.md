# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入最长五分钟、8–48 kHz、单或双声道的 PCM16 WAV。在谱图上平移、缩放、跳听，用鼠标圈选或表单输入时频选区，生成十秒内的成对试听，切换原声与修复对听后再导出整段 PCM WAV。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm test
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 录音识别。上传以二进制流式落到临时文件，保留声道数、采样率和帧数；截在帧中间的文件提示不完整并拒绝生成。
- 谱图浏览。视区谱图只计算可见窗，固定聚合最多 160 列，平移缩放不改变选区的原始时频坐标。
- 频带衰减。六秒内沿用渐变重建；六秒以上仅在选框内平滑衰减目标频带，圈外频格增益恒为 1、圈外采样逐样保留，重叠相加保证跨边界连续。
- 分段对听。任意位置发起最长十秒试听，原声与修复声同帧区间、同窗表，重叠部分与整段下载逐样一致。
- 旁路与导出。无选区输出与源逐字节相同；下载保留全段起点、采样率、声道和帧数。
- 有界内存。固定窗长、视区、试听长度和选区数时，浏览器与服务端工作内存不随总帧数增长。

## 测试

- `node tests/engine-check.mjs`：流式重建、分段一致、圈外原样、截断识别。
- `node tests/http-check.mjs`：四个入口的端到端工作流与重叠逐样一致。
- `node tests/compat-check.mjs`：六秒内新入口与旧 `repair` 逐字节相同。
- `node tests/boundary-check.mjs`：时长、采样率、试听长度、选区边界。
- `node --expose-gc tests/memory-check.mjs`：工作内存不随总帧数增长。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。
