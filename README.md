# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入自己的 WAV，在谱图拖选或用表单输入数值。添加选区后生成修复，切换原声与修复试听，再下载 PCM WAV。也可打开上滑音演示，把与配乐混录的机关平音在原时段改成匀速上滑音。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 录音识别。保留声道数、采样率和帧数。
- 谱图计算。窗长变化使真实频格宽度变化。
- 频带衰减。污染选区附近频带能量下降。
- 旁路重建。无选区的输出逐帧等价。
- 量测和 PCM 输出。保持源帧数并给出逐声道差值。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。

## 上滑音工作流

- 圈选时段。在谱图拖出机关平音所在的时间与频率范围，时段自动填入上滑音表单。
- 填写参数。基频搜索范围、要移动的谐波阶数（逗号分隔）、各阶边带半宽（一个值或逐阶）和目标基频起止值。
- 先辨识再生成。辨识通过会显示基频与各阶独占声明频带；无法唯一辨认或频带间隔不足 4 Hz 时停在原声并说明原因。
- 对听与下载。新声线在原时段匀速上滑、各阶随基频变化并保留原响度起伏，仅头尾各 20 毫秒过渡，圈外逐样保留，采样率、声道数和时长不变。
