# 听纹修复

打开页面获得内置三秒录音及一块污染选区。可导入自己的 WAV，在谱图拖选或用表单输入数值。添加选区后生成修复，切换原声与修复试听，再下载 PCM WAV。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4813`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 录音识别。保留声道数、采样率和帧数。
- 谱图计算。窗长变化使真实频格宽度变化。
- 频带衰减。污染选区附近频带能量下降。
- 旁路重建。无选区的输出逐帧等价。
- 量测和 PCM 输出。保持源帧数并给出逐声道差值。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。

## 房间响应导出与校样

在「房间响应」面板导入单声道探测音和双声道收音（同采样率 PCM16 WAV），填写收音起播标记（帧）与响应帧数后导出。服务端按声道做最小二乘反卷积并用整数码微调，使导出件重放探测音时，自标记起的完整尾部与收音逐帧差至多 2 码、首个超 2 码帧一致；探测音静音、收音缺尾或指定长度无合格响应会拒绝并说明。

导出的双声道 PCM16 房间响应可直接试听与下载。再导入一段同采样率单声道干声即可生成纯房间声校样：固定点卷积以 32768 为满幅、半码远离零、超幅裁切，重导同一响应的校样逐帧相同，并保留完整尾部、电平和声道顺序，试听与下载共用同一成品。原频谱修复入口不受影响。
